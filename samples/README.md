# 테스트용 예제 파일

탭1(문서 양식 변환기)에서 **원본(A)** 에 `(원본)` 파일을, **타겟 양식(B)** 에 같은 번호의 `(타겟)` 파일을 넣고 [구조 분석]을 누르세요.
②단계의 **시각화** 스위치를 켜면 연결 보기·결과 미리보기·값 고치기를 쓸 수 있습니다(기본은 꺼짐).

마음대로 고쳐서 써도 됩니다. 원래대로 되돌리려면 `node tests/e2e/make-samples.js` 를 실행하세요.

| 번호 | 원본(A) | 타겟(B) | 무엇을 확인할 수 있나 |
|---|---|---|---|
| 01 | `01_기본_직원명부(원본).xlsx` | `01_기본_회사양식(타겟).xlsx` | 기본 흐름. 동의어(성명←이름, 부서명←부서), 비슷한 이름(입사릴←입사일, [맞음] 확인), 연결 없음(연락처 → 휴대폰 추천), 중복 행(7행 = 5행), 제목 행이 있고 B2에서 시작하는 표(원본 행 번호 4~7), 값이 하나도 없는 컬럼(빈칸컬럼, 숨김) |

## 고쳐 보면 좋은 것

- **01**: 원본 6행의 휴대폰을 지우고 연락처를 [필수]로 지정 → 필수 빈칸 표시 확인. 미리보기에서 그 칸을 더블클릭해 직접 채우고 저장.
- **01**: 타겟의 "입사릴"을 "입사일"로 고치면 비슷한 이름 대신 같은 이름으로 연결됩니다.
- **02**: 타겟에 컬럼을 더 붙여 넣거나(수백 개도 가능) 원본에 행을 늘려 속도를 확인.
- **03**: 거래액 칸에 "협의" 같은 글자를 넣으면 그 열은 숫자 대신 글자로 저장됩니다(엑셀 원본과 같은 규칙).
- **04**: 결과 파일을 엑셀로 열어 ₩·%·날짜 형식이 그대로인지 확인.
