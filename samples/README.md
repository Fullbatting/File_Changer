# 테스트용 예제 파일

탭1(문서 양식 변환기)에서 **원본(A)** 에 `(원본)` 파일을, **타겟 양식(B)** 에 같은 번호의 `(타겟)` 파일을 넣고 [구조 분석]을 누르세요.
②단계의 **시각화** 스위치를 켜면 연결 보기·결과 미리보기·값 고치기를 쓸 수 있습니다(기본은 꺼짐).

마음대로 고쳐서 써도 됩니다. 원래대로 되돌리려면 `node tests/e2e/make-samples.js` 를 실행하세요.

## 고쳐 보면 좋은 것

- **01**: 원본 6행의 휴대폰을 지우고 연락처를 [필수]로 지정 → 필수 빈칸 표시 확인. 미리보기에서 그 칸을 더블클릭해 직접 채우고 저장.
- **01**: 타겟의 "입사릴"을 "입사일"로 고치면 비슷한 이름 대신 같은 이름으로 연결됩니다.
- **02**: 타겟에 컬럼을 더 붙여 넣거나(수백 개도 가능) 원본에 행을 늘려 속도를 확인.
- **03**: 거래액 칸에 "협의" 같은 글자를 넣으면 그 열은 숫자 대신 글자로 저장됩니다. 등록일을 `2026/1/5`, `2026. 1. 5.`처럼 다른 표기로 바꿔도 날짜로 읽고, "미정" 같은 글자를 섞으면 그 열은 글자로 둡니다.
- **04**: 결과 파일을 엑셀로 열어 ₩·%·날짜 형식이 그대로인지 확인.
- **05**: 급여 파일의 합치는 방식을 "양쪽 행 모두"로 바꾸면 급여에만 있는 "퇴사자" 행도 들어갑니다(원본 행 칸에 "05_합치기_급여(추가 원본) 7"처럼 표시). 분석 결과 아래에 빠지거나 덧붙인 행이 이유별 행 번호와 함께 나옵니다. "전체 시트도 맨 앞에 넣기"를 켜면 부서별 시트 앞에 전체 시트가 하나 더 생깁니다.
- **06**: ①단계의 **헤더 행** 목록에서 다른 행을 골라 보면 인식 결과와 데이터 행 수가 바로 바뀝니다. CSV의 **인코딩**을 UTF-8로 바꾸면 깨진 글자 수를 알려줍니다.
- **06**: 매출 파일에서 "앞자리 0 무시"를 켜고 [구조 분석] → 저장하면 ③단계에 저장한 파일을 다시 열어 확인한 결과(시트·헤더·값 비교, 행 수 흐름)가 나옵니다.
